# Paradise Nursery — e-plantShopping

A React and Redux Toolkit shopping cart application for an online houseplant shop.

## Features
- Landing page with Paradise Nursery branding and a Get Started button
- Navigation between Home, Plants, About Us, and Cart
- Plant listings grouped into Aromatic Plants and Medicinal Plants
- Add plants to the cart
- Increase/decrease quantities and delete cart items
- Cart item subtotals and overall total
- Continue Shopping and Checkout buttons

## Technologies
- React + Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## GitHub
Create a **public** repository named `e-plantShopping`, then commit and push all project files.
